One rule, infinite detail

Everything in the explorer comes from one tiny formula, repeated over and over. Here is how it works, with tools you can poke at.

1 · The ruleSquare it, add c, repeat

Pick a number c. Start with z = 0 and apply this rule again and again, feeding each answer back in:

z  →  z² + c

Try c = 1: you get 0, 1, 2, 5, 26, 677, … and it races off to infinity. Try c = −1: you get 0, −1, 0, −1, … and it bounces back and forth forever. That's the whole question the Mandelbrot set asks:

The Mandelbrot set is every c for which the sequence stays bounded (does not run off to infinity).

Try it on the number line

Slide slowly from right to left. Above c = ¼ everything escapes. Between ¼ and −¾ the sequence settles on one value. Past −¾ it splits into a 2-cycle, then a 4-cycle, then 8, then chaos, with calm windows inside it (try −1.76 for a 3-cycle). At exactly −2 it lands on 2 and stays there. Below −2 it escapes again. So on the number line, the Mandelbrot set is just the stretch from −2 to ¼.

2 · Into the planeComplex numbers turn a line into a picture

The magic starts when c can be a complex number: a point a + bi on a flat plane, where i² = −1. Adding is just sliding the point. Squaring is a geometric move: the distance from 0 gets squared and the angle doubles.

What squaring does

Drag z around. Inside the circle of radius 1, squaring pulls points inwards. Outside it, squaring flings them further out. Every step of the rule is "double the angle, square the distance, then slide by c". That spinning and stretching is what makes the shapes spiral.

4 · Julia setsThe same rule, flipped

A Julia set uses the same rule, z → z² + c, but flips which number you vary. For the Mandelbrot set you always start at z = 0 and try every possible c. For a Julia set you fix one c and try every possible starting point z. The starting points whose sequence stays bounded form the (filled) Julia set for that c. So there's one Mandelbrot set, but a different Julia set for every value of c.

They're tied together by a classic theorem: the Mandelbrot set is exactly the set of values of c whose Julia set is connected, meaning it's all in one piece.

  • If c is inside the Mandelbrot set, its Julia set is one connected shape.
  • If c is outside, the Julia set shatters into infinitely many separate specks, called "Fatou dust".

The reason is that the starting point 0 is special for z² + c: the shape of the whole Julia set depends on whether the orbit of 0 escapes. That orbit is exactly what the Mandelbrot set tests. In that sense the Mandelbrot set is a map, or catalogue, of all the Julia sets.

The shape also carries over. A c deep inside the main cardioid gives a slightly wobbly circle, and a c in the period-3 bulb gives a "rabbit" with three ears meeting at each joint. A c on the edge gives the most intricate Julia sets, and if you zoom into the Mandelbrot set near that c, you often find patterns that look like that c's Julia set.

5 · Why the circle?Once past 2, there's no way back

If a point of the orbit ever gets further than 2 from the centre, it will escape for sure. In the Mandelbrot sequence, |z| is at least |c| by the time it passes 2, and then

|z² + c| ≥ |z|² − |c| ≥ |z|² − |z| = |z| (|z| − 1)

Each step at least multiplies the distance by |z| − 1, which is more than 1 once you are past 2.

With |z| > 2, the factor |z| − 1 is bigger than 1, so every step pushes it further out, faster and faster. That's why the computer can stop as soon as it crosses the circle: it already knows the answer. It also means the whole set fits inside that circle.

6 · ColoursHow fast it escapes

Strictly, a point is either in the set (black) or not. The colours in the explorer show how many steps each outside point took to cross the circle. Below, only N steps are checked. Black is "hasn't escaped yet". Raise N and watch the black shape shrink towards the real set.

Survivors after N steps

After 1 step, the survivors are just the disc of radius 2. After 2 steps it's an oval, after 3 a pear, and every extra step carves in more detail. The real set is what's left after infinitely many steps. The explorer raises N automatically as you zoom: thousands of steps at ×10¹⁰, tens of thousands deeper down. The smooth colour bands come from also measuring how far past the circle the last step landed.

7 · Bulbs and periodsThe set counts for you

Every bulb has a number: the length of the cycle its orbits fall into (you saw this in the orbit tool). And you can read that number off the picture: count the spokes on the antenna sticking out of a bulb. The top bulb has 3 spokes and a 3-cycle. Its neighbour has 4 spokes and a 4-cycle.

Between two bulbs, the biggest bulb in the gap has the sum of their numbers. Between the 2-bulb and the 3-bulb sits a 5-bulb, between 3 and 5 an 8, then 13, 21, 34… That's the Fibonacci sequence, appearing in the bulbs. (Mathematicians call this Farey addition.)

8 · The fig treeThe real line, unfolded

Back to the number line. For each c, run the rule for a long time and plot every value the sequence keeps visiting. Line that up under the set and something remarkable shows: each time the set pinches to a new bulb, the line splits in two (1 → 2 → 4 → 8 …). Then chaos sets in, broken by calm windows that sit exactly where the baby Mandelbrots are.

The set (top) and where the orbit settles (bottom)

This picture is famous in its own right: it's the "bifurcation diagram" of the logistic map x → r·x(1 − x), used in population models. It's the same rule in disguise: substitute z = r(½ − x) and you get z² + c with c = r/2 − r²/4. The splits come closer and closer, each gap about 4.669 times shorter than the one before. That's Feigenbaum's constant, and it turns up in dripping taps, fluid flow and electronic circuits too.

9 · Other exponentsMultibrot sets: change the 2

Nothing forces the exponent to be 2. Swap it for another number d and the rule becomes

z  →  zd + c

The shapes you get are called Multibrot sets, and d = 2 is the Mandelbrot set itself. Drag the slider: it snaps to whole numbers, and in between it shows the fractional powers.

Change the exponent

Explore this one in the explorer →
  • Whole numbers (3, 4, 5 …) give tidy cousins with d − 1 identical lobes arranged around the centre: two for z³, three for z⁴, four for z⁵. Everything else carries over: bulbs, antennas, baby copies, and the connected-or-dust rule for Julia sets. That's because zd still has just one critical point, 0, so the orbit of 0 still decides everything. As d grows, the set gets rounder and closes in on the circle of radius 1.
  • Fractional powers (like 2.5) have no single answer: z2.5 could mean several different numbers, and the computer has to pick one. The usual choice jumps along a line, and those jumps show up as seams and slices in the picture. Sweep from 2 to 3 and you can watch a second lobe grow out of the seam until it becomes the symmetric cubic set. The pictures are pretty, but the clean theory breaks: no guaranteed connectedness, and no tidy Julia rule.

Two stranger cases, not in the explorer. An exponent just above 1, like 1.000001, squeezes the set to a microscopic speck around 0. Most programs draw it wrong, because "past 2 means gone" no longer holds when squaring is that weak. A complex exponent, like 2 + 0.3i, adds a twist to every step, so the whole set comes out swirled and lopsided: more art than theory.

In the explorer, open Settings → Exponent, or pick one of the Multibrot cousins at the end of Places.

10 · Going deepHow the explorer reaches ×10²⁵⁰

Phones do arithmetic with about 16 significant digits. Past a zoom of about 10¹³, neighbouring pixels become the same number and the picture breaks into blocks. The explorer gets round that in three steps:

  • One precise path. It works out the orbit of the centre point with whole-number arithmetic carrying as many digits as the zoom needs (hundreds of bits).
  • Only the differences. Every other pixel is tracked as a tiny offset from that path (perturbation). Tiny numbers are no problem for ordinary arithmetic, even at 10⁻³⁰⁰.
  • Skip the boring part. For the first few thousand steps all those offsets grow almost in lockstep, so a short polynomial predicts them, and the app jumps straight past (series approximation).

The first two tricks work for the Multibrot cousins with whole-number exponents too, so they also zoom to ×10²⁵⁰. Fractional powers stop at ×10¹¹: their seams make deeper zooms meaningless.

Three facts

The set is all one connected piece (Douady and Hubbard proved it in 1982), its area is about 1.506 though nobody knows the exact value, and its edge is so wrinkled that it counts as 2-dimensional (Shishikura, 1998).
